# Projeto Crefisa — Power BI

Relatório em Power BI para explorar indicadores de empréstimos, filiais e linhas de crédito.

## Páginas do relatório

- **HOME:** página inicial.
- **DASHBOARD:** faturamento, quantidade de empréstimos, ticket médio e lojas ativas, com filtros e gráficos por filial e linha de crédito.
- **DETALHAMENTO:** consulta dos registros de empréstimos.
- **ANÁLISE HIERÁRQUICA:** exploração dos valores por ano, filial e linha de crédito.

## Como abrir

1. Baixe o arquivo `Projeto Crefisa Noite.pbix`.
2. Abra o arquivo no Power BI Desktop.
3. Navegue pelas páginas e utilize os filtros do relatório.

O ícone do LinkedIn no canto inferior esquerdo do **DASHBOARD** aponta para o perfil de [Gabriela Carvalho](https://www.linkedin.com/in/gabriela-carvalho-2700a7182/). No Power BI Desktop, utilize **Ctrl + clique** para seguir o link.
